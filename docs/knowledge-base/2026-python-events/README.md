# Python events in 2026

Structured recap of Python community events in 2026, serving information retrieval for further analysis: for each event, we collect its talks — titles, abstracts, speakers, and descriptions — with links back to the online sources the data came from.

The underlying research that identified these events lives in <a href="../../../early-research/2026-python-events.md">Python community events in 2026</a>, with the FOSDEM data-collection approaches in <a href="../../../early-research/fosdem-data-sources.md">FOSDEM data sources</a>.

## Events covered

The events below are grouped as in the research file. The per-event data link points at the folder where that event's talk data lives; events not yet collected are marked accordingly.

## Method

- The data source is each event's own website — schedule pages and XML/JSON exports where the event offers them.
- Every talk entry links back to its online source.
- FOSDEM data comes from the official Pentabarf XML export (see <a href="../../../early-research/fosdem-data-sources.md">FOSDEM data sources</a> for the export variants and their quirks).
