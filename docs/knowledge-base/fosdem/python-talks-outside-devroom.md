# Python talks outside the Python devroom at FOSDEM

!!! note "Draft"

    This page is a working research note. The flagging of "Python involved" talks is deliberately broad and judged by hand from titles and abstracts, so expect false positives and omissions. See [Borderline and uncertain flags](#borderline-and-uncertain-flags) for the cases we are least sure about.

The [Python and other programming languages devroom](https://fosdem.org/2026/schedule/track/python/) is not the only place Python shows up at FOSDEM. A lot of Python-related content lives in other devrooms: energy system modelling, robotics, quantum computing, scientific research, packaging and supply chain security, and more. This page collects that content for the last three editions.

## Method

We scanned every talk in the official Pentabarf XML schedules and flagged anything outside the Python devroom where Python (or its ecosystem) appeared central to the talk, the speaker's work, or the speaker's affiliation:

- [FOSDEM 2024 schedule XML](https://archive.fosdem.org/2024/schedule/xml)
- [FOSDEM 2025 schedule XML](https://fosdem.org/2025/schedule/xml)
- [FOSDEM 2026 schedule XML](https://fosdem.org/2026/schedule/xml)

The definition of "Python involved" is deliberately broad, covering:

- Makers of the language and its ecosystem: core developers, PyPA, packaging, CPython internals.
- Users of Python-based applications: Home Assistant, Odoo, Jupyter, Apache Airflow, and similar.
- Data, ML, and scientific stacks: pandas, NumPy, scikit-learn, PyTorch, JAX, web frameworks, scripting, automation, and games.
- Talks where the speaker's affiliation suggests Python (Anaconda, PyCharm, PyScript, and similar), even if the talk itself is not Python-branded.

Each talk was judged by title plus abstract, with keyword pre-screening followed by manual review. The raw machine-readable output of that process, including per-talk confidence scores, is kept in [`python-outside-devroom-raw.json`](https://github.com/thibaudcolas/python-at-fosdem/blob/main/docs/knowledge-base/fosdem/python-outside-devroom-raw.json).

Counts per edition: 41 flagged talks in 2024, 56 in 2025, and 75 in 2026 (172 total, including borderline cases). The 2026 figures reflect a schedule snapshot taken on 2026-09-20 (scan date: 2026-09-20); FOSDEM 2026 was still amending its schedule when scanned, so the 2026 list and counts are not final. The growth across editions reflects both more Python content outside the devroom and, in 2026, a much larger overall schedule.

## Where Python content lives outside the devroom

A handful of non-Python devrooms host Python content every year, and they are the ones to watch when planning or looking for Python-adjacent talks.

- **[HPC, Big Data & Data Science](https://fosdem.org/2026/schedule/track/hpc-big-data-data-science/)** — the most consistent Python-adjacent devroom across all three years. Jupyter tooling, Python bindings, scientific computing, and parallel Python runtimes.
- **[Open Research](https://fosdem.org/2026/schedule/track/open-research/)** — Jupyter Book, Jupyter notebooks in research workflows, reproducible research, and Python scientific software sustainability.
- **[Robotics and Simulation](https://fosdem.org/2026/schedule/track/robotics-and-simulation/)** — ROS 2 testing, PyCRAM, Upkie, and PlotJuggler. Python is the primary language of the ROS 2 ecosystem.
- **[Energy](https://fosdem.org/2026/schedule/track/energy/)** — PyPSA, OpenSTEF, and FlexMeasures. Energy system modelling is a heavily Python-based field, with a dedicated presence every year.
- **[Embedded, Mobile and Automotive](https://fosdem.org/2026/schedule/track/embedded-mobile-and-automotive/)** — MicroPython, Home Assistant, Snagboot, and MicroPythonOS. Python for microcontrollers and embedded tooling.
- **[Quantum Computing](https://fosdem.org/2025/schedule/track/quantum/)** — nearly every quantum software talk in 2025 involved a Python SDK (Qumat, qBraid, PyTKET, Unitary).
- **[Package Management](https://fosdem.org/2026/schedule/track/package-management/)** and the SBOM/supply-chain devrooms — PyPI, Python packaging, attestations, and dependency analysis come up repeatedly.
- **[Lightning talks](https://fosdem.org/2024/schedule/track/lightning_talks/)** and the **[main tracks](https://archive.fosdem.org/2024/schedule/track/main_track_k_building/)** occasionally carry Python content, usually better represented in dedicated devrooms.

AI and LLM-adjacent devrooms ([AI Plumbers](https://fosdem.org/2026/schedule/track/ai/), [Low-level AI Engineering and Hacking](https://fosdem.org/2025/schedule/track/ai/), AI/ML devrooms) are a growing home for Python content, mostly via PyTorch, ONNX, and Python-based LLM tooling.
