# 2027 proposal brief

We have been given clear feedback in 2026, after running a shorter devroom than we would have hoped. We need to address this feedback in 2027.

The feedback:

> Clearly, they want less "mainstream" devrooms, especially devrooms where official events exist.
>
> If we want to increase our chances next year to have a full day, we might find a specific theme. This theme can be linked with the Python ecosystem.
>
> In our proposal, we can propose several themes to let the FOSDEM team select the best theme for them. We can also indicate we are open to collaborate with another devteam: for example, they have decided to merge all databases rooms in one room to free up several slots.

## Our response

### Different themes

We are going to draft three separate themes, and select one to go ahead with. The goal is to develop themes of 'Python' that are not as broad as just 'Python', but still broad enough that they can attract a wide range of participants and speakers.

The themes earmarked so far:

- AI-free Python. Showcasing work that doesn’t involve LLMs or other AI-driven technologies. Data science, web development, automation, and other areas of Python where AI is not the primary focus.
- Inclusive Python / social good Python. Highlighting projects and initiatives that use Python to promote inclusivity, accessibility, and social impact. This could include educational tools, community-driven projects, and applications aimed at solving societal challenges.
- Control: Python. Just the usual broad Python theme, still worth considering with a slight refresh.

### Different angle

The theme(s) are important but in addition we want to freshen up other aspects of the devroom experience. We want to emphasize:

- Collaboration with other devrooms and Python community organizations. Making sure we signpost related devrooms for our audience, and work with the PSF / EPS / DSF if they propose and obtain a stand like in 2026.
- A bias on topics and formats that encourage discussions. Possibly a panel format, or encouraging proposals that include audience participation. Making sure we leave proper time for lightning talks.
- Community building elements. Stickers table, informal Python meetups, and working with PSF / EPS / DSF to showcase upcoming in-person Python events in 2027.

A broader goal is to express the importance of community, and in-person gatherings, which tremendously helps people make sense of the shifting tech landscape.
