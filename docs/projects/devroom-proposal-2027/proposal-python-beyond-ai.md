# Devroom proposal 2027: Python beyond AI

## Proposal title

Python beyond AI

## Elaborate description (seen only by the FOSDEM program team)

FOSDEM has asked for less mainstream devrooms and more specific themes. This proposal answers that with a theme connected to the Python ecosystem: specific enough to be a room of its own, broad enough to fill a diverse program.

The theme is _Python beyond AI_: the room for everything in Python that AI-focused devrooms do not cover. This is not an anti-AI position. It is a room for the craft of Python — software, infrastructure, science, and tooling in which AI is not the subject. The devroom's own history backs this up: a keyword scan of the 206 archived devroom talks finds AI/ML core-subject talks in only 4 of them, while the largest clusters are scientific and data work, education and community, and web and Django. FOSDEM already hosts AI-focused devrooms — AI and Machine Learning, AI Plumbers, and Low-level AI Engineering and Hacking — so Python's AI content has homes there; the rest of Python needs one here. It is also the sharpest answer to "less mainstream": AI is what is mainstream in 2027, and the unglamorous rest of Python is the underserved topic.

Examples of the topics we would like to see:

- Web frameworks and CMSes in production (Django, Flask, FastAPI, HTMX)
- Infrastructure and automation in Python (configuration management, infrastructure as code)
- Packaging and developer tooling (uv, pixi, monorepos, testing, CI, linting)
- Data engineering and analytics without machine learning (DuckDB, PyArrow, ETL)
- Scientific Python and research software
- Performance: profiling, free-threaded Python (3.14t and later), the GIL's future
- Embedded Python, microcontrollers, desktop and CLI applications
- Python for education and teaching
- Security and supply-chain health of Python packages
- Maintaining and sustaining open source Python projects
- Contributing to CPython and the ecosystem
- What's new in Python 3.14 / 3.15 / 3.16 (non-AI developments)

Scope, stated plainly: talks whose primary subject is AI or machine learning — including LLMs, model training, inference, and AI agents — belong in FOSDEM's AI-focused devrooms, and we will say so in our call for participation and redirect submitters there. This is collaboration, not exclusion — we would rather send a good AI talk to the right room and hear from a different part of the ecosystem ourselves. To make that concrete, we will signpost these devrooms in our call for participation and seek to coordinate with them if they are accepted: the AI and Machine Learning devroom, AI Plumbers, and Low-level AI Engineering and Hacking, as well as Package Management, Software Performance, Embedded/Mobile/Automotive, and the web- and CMS-related devrooms.

How the room runs. A 25-minute talk format including Q&A, plus a guaranteed lightning-talk session (both the 2025 and 2026 devrooms ran one). At least one panel or community-conversation slot, and we welcome proposals that include audience participation. We signpost related devrooms in our call for participation and on site, and we invite adjacent devrooms to suggest speakers. On site we keep the community elements that make the room a gathering point: a stickers table, an informal Python meetup, and, if the Python Software Foundation, the EuroPython Society, and the Django Software Foundation obtain a stand as they did in 2026, a stand coordinated with them to showcase 2027 in-person Python events. In-person gatherings are what help people make sense of a fast-shifting tech landscape, and this room is built to create them.

We are applying for a half-day room. We are open to having it paired with a related devroom, or to combining with another Python-related proposal — as the program team has done by merging related rooms when that frees slots. We will have at least two named devroom managers, as required.

## Why does this proposal fit FOSDEM

This is a themed room that deliberately covers the non-AI part of the Python ecosystem, rather than another general Python track. The devroom's own archive shows where its center of gravity sits: a keyword scan of its 206 talks since 2013 finds AI or machine learning as the core subject in only 4 of them, while the far larger clusters are scientific and data work, education and community, and web and Django.

Python and its ecosystem are open by default: the language is developed in the open (CPython), its packaging is built around open standards, and the vast majority of its packages are open source. That openness, together with a low barrier to entry — abundant teaching material, good documentation, and a welcoming community — brings people into free and open source software, often as their first programming language.

The Python devroom has run every year since 2013, is packed every year, and routinely receives more high-quality submissions than we can accommodate. Python is also woven through the rest of FOSDEM: 41 Python-involved talks in other tracks in 2024, 56 in 2025, and 75 in the 2026 schedule snapshot (a broad, hand-judged estimate that includes borderline matches, where the growth partly reflects a larger 2026 schedule), spread across devrooms from AI and Machine Learning to Energy, Open Research, and Bioinformatics. A themed Python room gives that community a home and a partner network rather than an island.

The room is run by organizers and volunteers drawn from across the Python community — the Python Software Foundation, the EuroPython Society, the Django Software Foundation, and local user groups. It is a winter gathering point for the European Python community, complementing the large summer conferences rather than duplicating them.
