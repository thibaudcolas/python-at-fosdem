# Devroom proposal 2027: Python

## Proposal title

Python

## Elaborate description (seen only by the FOSDEM program team)

FOSDEM has asked for less mainstream devrooms and more specific themes. This proposal takes the broad Python theme and refreshes it on the other axis — how the room runs — rather than narrowing its subject. Python is specific enough to be a room of its own and broad enough to fill a diverse program.

The theme is _Python_ in its full breadth — the language, its ecosystem, and its applications — as the community's annual European gathering. Continuity is the point: the devroom has run every year since 2013, its rooms are packed, and its call for participation is routinely oversubscribed. What is new for 2027 is not a narrower subject but the way the room runs, described below.

Some feedback suggests that devrooms are less necessary where an official event already exists. We would like to address that directly. PyCon US and EuroPython are ticketed, single-community conferences held elsewhere in the year; FOSDEM is free, volunteer-run, in winter, and cross-project. The Python devroom is the one place where the Python community meets in person alongside FOSDEM's other devrooms, and we would like to keep it that way: we see EuroPython 2026 and the other official events as complementary, not competing.

Examples of the topics we would like to see:

- How to start as a Python developer
- Code infrastructure & starting new projects (uv, pixi)
- Testing/CI best practices
- Performant Python code; free-threaded Python (3.14t and later)
- Sustainable Python code
- How to do my cool thing in Python
- Python as a tool for education
- How to contribute to the Python language
- Python 3.14 / 3.15 / 3.16: what's new?
- Python in data analysis & visualization
- The scientific Python ecosystem
- Reproducibility and best practices (lockfiles and beyond)
- How to write secure Python code
- Python governance; success stories; new projects
- Interoperability and cross-language bindings

How the room runs. A 25-minute talk format including Q&A, plus a guaranteed lightning-talk session (both the 2025 and 2026 devrooms ran one). At least one panel or community-conversation slot, and we welcome proposals that include audience participation. We signpost related devrooms in our call for participation and on site, and we invite adjacent devrooms to suggest speakers. On site we keep the community elements that make the room a gathering point: a stickers table, an informal Python meetup, and, if the Python Software Foundation, the EuroPython Society, and the Django Software Foundation obtain a stand as they did in 2026, a stand coordinated with them to showcase 2027 in-person Python events. In-person gatherings are what help people make sense of a fast-shifting tech landscape, and this room is built to create them.

Because this theme is broad, it is also the one that overlaps most with other devrooms, so we make the partnership explicit. Drawing on where Python content actually landed in other rooms, we will signpost these devrooms in our call for participation and seek to coordinate with them if they are accepted: the AI and Machine Learning devroom, HPC/Big Data/Data Science, Robotics and Simulation, Open Research, Energy, and Package Management.

We are applying for a half-day room. We are open to having it paired with a related devroom, or to combining with another Python-related proposal — as the program team has done by merging related rooms when that frees slots. We will have at least two named devroom managers, as required.

## Why does this proposal fit FOSDEM

This option rests on continuity and demand. The devroom has run every year since 2013, is packed every year, and routinely receives more high-quality submissions than we can accommodate. The half-day plan turns the schedule into a working session: panels and audience participation, guaranteed lightning talks, and cross-devroom coordination.

Python and its ecosystem are open by default: the language is developed in the open (CPython), its packaging is built around open standards, and the vast majority of its packages are open source. That openness, together with a low barrier to entry — abundant teaching material, good documentation, and a welcoming community — brings people into free and open source software, often as their first programming language.

Python is also woven through the rest of FOSDEM: 41 Python-involved talks in other tracks in 2024, 56 in 2025, and 75 in the 2026 schedule snapshot (a broad, hand-judged estimate that includes borderline matches, where the growth partly reflects a larger 2026 schedule), spread across devrooms from AI and Machine Learning to Energy, Open Research, and Bioinformatics. A Python room gives that community a home and a partner network rather than an island.

The room is run by organizers and volunteers drawn from across the Python community — the Python Software Foundation, the EuroPython Society, the Django Software Foundation, and local user groups. It is a winter gathering point for the European Python community, complementing the large summer conferences rather than duplicating them.
