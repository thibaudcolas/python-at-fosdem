# Devroom proposal 2027: Python for social good

## Proposal title

Python for social good

Alternative options:

- Python for impact (vague?)
- Python with purpose (mushy, generic?)
- Python for people (not super clear but human-centered is nice?)

## Elaborate description (seen only by the FOSDEM program team)

There has been a Python devroom at FOSDEM for 10+ years. For 2027 we have new organizers and we want to propose something a bit different, that is a direct response to the current challenges of our community. Our overall goal is to **create a space where Python practitioners can collectively make sense of our evolving industry**. To achieve that, we’re proposing a Python devroom with a more specific theme, and adjusting what we plan to run at FOSDEM to encourage more active participation from attendees.

The theme we’re proposing is "Python for social good". We want a room for Python work of all kind that’s in service of a positive purpose for people / society / the planet. This can be education, research, civic tech, environmental sustainability, humanitarian work, accessibility tech, and many more. This is inspired by the [2025 Inclusive Web devroom](https://archive.fosdem.org/2025/schedule/track/inclusive-web/), which brought together a vast range of 'web' practitioners with shared values. We think this theme is broad enough to be viable, specific enough that it won’t overlap with the Python presence in other devrooms (scientific Python, AI plumbers, ML). Compared to mainstream Python events that have to cater to industry sponsors’ needs, it’s a theme that is more focused on the strong values of the Python community, while being very welcoming / approachable for people who are new to it.

Illustrative topics, with selected recent examples from 2026 events:

- Education and outreach: teaching tools, accessible tutorials, classroom material (for example "Making Tech Tutorials Accessible: Practical Techniques for Educators", PyCon DE & PyData 2026)
- Civic tech and public sector services (for example "ATLAS: Building a Zero-Budget IT Service Management Platform with Django in the Public Sector", DjangoCon Europe 2026; and "Building a sovereign digital workplace with the help of Python, an example of the French administration", FOSDEM 2026 Python devroom)
- Accessibility and inclusive design in Python tools and documentation
- Climate, energy, and environmental projects (for example "Python in Climate Tech: Vehicle-to-Grid", PyCon DE & PyData 2026)
- Community infrastructure: the tools that run Python communities (for example "No More Spreadsheets! Building PyLadiesCon Infrastructure with Python and Django", PyCon Portugal 2026)
- Diversity and inclusion as engineering practice (for example "How We Built an Inclusive Data Organization: Careers, Community & 50% Women", PyCon DE & PyData 2026)
- Humanitarian, health, and nonprofit applications
- Open science and reproducible research for public benefit
- Sustaining community-run open source: funding, governance, maintainer health

Format matters for this theme, so we plan it deliberately: project showcases, tutorials and workshops, and panels with community organizers (PyLadies, Django Girls, and the Python Software Foundation, EuroPython Society, and Django Software Foundation). The panel or community-conversation format is a core part of this program, not a side item — the 2026 European programs already show the appetite, from "Django and AI: A Community Conversation" at DjangoCon Europe 2026 to the "PyLadies Fireside Chat" at PyCon DE & PyData 2026.

How the room runs. A 25-minute talk format including Q&A, plus a guaranteed lightning-talk session (both the 2025 and 2026 devrooms ran one). At least one panel or community-conversation slot, and we welcome proposals that include audience participation. We signpost related devrooms in our call for participation and on site, and we invite adjacent devrooms to suggest speakers. On site we keep the community elements that make the room a gathering point: a stickers table, an informal Python meetup, and, if the Python Software Foundation, the EuroPython Society, and the Django Software Foundation obtain a stand as they did in 2026, a stand coordinated with them to showcase 2027 in-person Python events. In-person gatherings are what help people make sense of a fast-shifting tech landscape, and this room is built to create them.

To make the cross-project reach concrete, we will signpost these devrooms in our call for participation and seek to coordinate with them if they are accepted: FOSS Educational Programming Languages, FOSDEM junior, Inclusive Web, Community, Translations, Open Research, and Legal and Policy.

We are applying for a half-day room. We are open to having it paired with a related devroom, or to combining with another Python-related proposal — as the program team has done by merging related rooms when that frees slots. We will have at least two named devroom managers, as required.

## Why does this proposal fit FOSDEM

FOSDEM favors communities without large corporate backing and encourages cross-project collaboration. Social-good Python is one such community: its work already appears scattered across FOSDEM and European Python events — education and Hedy in the FOSS Educational Programming Languages devroom and FOSDEM junior, public-sector Django in the Python devroom, climate and energy in the Energy devroom — rather than gathered in one place. This room would give it one.

Python and its ecosystem are open by default: the language is developed in the open (CPython), its packaging is built around open standards, and the vast majority of its packages are open source. That openness, together with a low barrier to entry — abundant teaching material, good documentation, and a welcoming community — brings people into free and open source software, often as their first programming language. That makes Python a natural home for much community-led, public-benefit work.

The Python devroom has run every year since 2013, is packed every year, and routinely receives more high-quality submissions than we can accommodate. Python is also woven through the rest of FOSDEM: 41 Python-involved talks in other tracks in 2024, 56 in 2025, and 75 in the 2026 schedule snapshot (a broad, hand-judged estimate that includes borderline matches, where the growth partly reflects a larger 2026 schedule), spread across devrooms from AI and Machine Learning to Energy, Open Research, and Bioinformatics. A themed Python room gives that community a home and a partner network rather than an island.

The room is run by organizers and volunteers drawn from across the Python community — the Python Software Foundation, the EuroPython Society, the Django Software Foundation, and local user groups. It is a winter gathering point for the European Python community, complementing the large summer conferences rather than duplicating them.
