# Devroom proposal 2027: Python for social good

## Proposal title

Python for social good

Alternative options:

- Python for impact (vague?)
- Python with purpose (mushy, generic?)
- Python for people (not super clear but human-centered is nice?)

## Elaborate description (seen only by the FOSDEM program team)

There has been a Python devroom at FOSDEM for 10+ years. For 2027 we have new organizers and we want to propose something a bit different, that is a response to the current challenges of our community. Our overall goal is to **create a discussion space where tech practitioners can collectively make sense of our evolving industry**. To achieve that, we’re proposing a Python devroom with a more specific theme, and adjusting what we plan to run at FOSDEM to encourage more active participation from attendees.

The theme we’re proposing is "**Python for social good**". We want a room for Python work of all kinds that’s in service of a positive purpose for people / society / the planet. This is inspired by the [2025 Inclusive Web devroom](https://archive.fosdem.org/2025/schedule/track/inclusive-web/), which brought together a vast range of 'web' practitioners with shared values. We think this theme is broad enough to be viable, specific enough that it won’t overlap with the Python presence in other devrooms (scientific Python, AI plumbers, ML). Compared to mainstream Python events that have to cater to industry sponsors’ needs, it’s a theme that’s more focused on the strong values of the Python community, while being very welcoming / approachable for people who are new to it. We see this theme as a direct response to the wider tech community struggling with ethics and purpose as more and more of tech people’s work involves AI.

Here are a few illustrative topics where we expect to see interesting Python projects:

- Civic tech and public sector services
- Accessibility and inclusive design in Python tools and documentation
- Climate, energy, and environmental projects
- Community infrastructure
- Humanitarian, health, and nonprofit applications
- Diversity and inclusion as engineering practice

The ‘code’ side of those projects will be varied: web tech (Django, FastAPI, etc), infrastructure and automation, developer tools, data engineering / machine learning, scientific python, embedded python. As with past years we will want talks that are about Python the language, and its ecosystem, and specific case studies.

—

We want to tweak the Python devroom recipe too. Within the overall FOSDEM talk format, here is what we’re planning (subject to feasibility) during the devroom:

- Lightning talks in 5min and ultra fast paced 2min format (shared slide deck, very streamlined)
- One or two panels or community Q&A slot (questions asked in advance, community-upvoted)
- Prioritize talk proposals that encourage community participation.
- A greater and better Python projects sticker table, that was very popular last year.
- A whiteboard or similar visual space to advertise other relevant community events / activities.

And outside the devroom:

- A community meetup either the day before or on the day of the devroom.
- Signposting other relevant devrooms to our community (AI plumbers, scientific computing, Rust, etc)
- If present, working in tandem with the shared stand of the EuroPython Society / Python Software Foundation / Django Software Foundation, like in 2026.

## Why does this proposal fit FOSDEM

This proposal aligns with the values of both the Python community and FOSDEM itself. It’s bringing together projects that share a similar purpose and language, to encourage collaboration and discussions. We think this is super important at this time, where there is a lot of anxiety in our community around AI and its impact on society.

With our proposed devroom organizers, we have a good mixture of FOSDEM regulars and past devroom organizers who are well placed to figure out which talk proposals we receive will be complementary with other devrooms rather than competing.
