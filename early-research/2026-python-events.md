# Python community events in 2026 — reference

Researched 2026-09-20. Companion to `fosdem-data-sources.md`. All dates/URLs below were
verified live on the cited pages unless noted.

## Scope & selection

- Events in **2026**, English-speaking, expected attendance well above 200
  (community conference scale).
- Focus on **Europe (in-person)** and **fully online / global** events; non-European
  events only when they have a strong online component or set the global calendar.
- Events ruled out by these filters (checked but excluded): meetups, sprints without a
  conference, events under ~200 attendees, non-English-first events with no international
  audience (e.g. PyConFR has a substantial French-only programme).

Official master calendar: <https://www.python.org/events/python-events/>.
Deadline-oriented cross-reference: <https://pythondeadlin.es/>.

## Ongoing community programmes (not single events, included for completeness)

- **Django Girls workshops** — free beginner Python/Django workshops, continuously
  organised worldwide; 2026 European/city editions included Amsterdam, Bologna,
  Barcelona, Munich, Cork. Calendar: <https://djangogirls.org/en/events/>.
- **PyData meetups** (Helsinki, Paris, Amsterdam, …) run alongside the conferences above;
  not individually catalogued here.

## Adjacent-but-not-strictly-Python (noted, not catalogued)

- **Compute! Paris 2026** (formerly PyData Paris), **Nov 25–26**, Paris — data/scientific
  computing event, Python-heavy but not a PyData-branded conference. <https://compute.events/paris2026/>
- **DjangoCon Africa 2026** — dates/location still TBA (2025 was Arusha, Tanzania).
- **PyCon Yerevan / PyData Yerevan 2026** — Jul 24–25, Yerevan, Armenia (Caucasus, often
  considered Europe-adjacent). <https://pydata.am/>
- **Python Brasil 2026** — Oct 14–19, Florianópolis, Brazil; included only for global
  calendar awareness, non-English-first. <https://2026.pythonbrasil.org.br/>

## How to keep this doc current

- Re-check the official Python.org calendar and each event's own site before relying on
  any single entry — several (PyCon Ireland venue, DjangoCon Africa, PyData Warsaw)
  were still in flux at research time.
- Conferences on this list with **no confirmed 2026 edition** that we deliberately did not
  catalogue as "upcoming": PyCon UK, PyCon Estonia (both cancelled 2026, aiming 2027),
  PyData Berlin, PyData Paris, PyData Finland (last held 2025; PyData Paris replaced by
  Compute! Paris 2026).
